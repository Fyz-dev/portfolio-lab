# Портфоліо

Персональне статичне портфоліо веб‑розробника, реалізоване як набір HTML‑сторінок та статичних ресурсів.

## Опис

Сайт демонструє навички та проєкти автора. Містить сторінки: головну, «Про мене», «Проєкти» та «Контакти».

## Особливості

- Сторінки: `index.html`, `about.html`, `projects.html`, `contacts.html`
- Статичні ресурси: папки `images/`, `audio/`, `video/`
- Проста структура — легко розгорнути або інтегрувати в більш складний стек

## Структура проєкту

```
portfolio/
├── .gitignore
├── README.md
├── index.html
├── about.html
├── projects.html
├── contacts.html
├── images/
│   ├── avatar.jpg
│   ├── preview-funfy-forum.png
│   └── preview-gunstore.png
├── audio/
│   └── music.mp3
└── video/
	└── intro.mp4
```

## Запуск локально

Просто відкрийте `index.html` у браузері або скористайтеся простим HTTP‑сервером.
