# Портфоліо

Персональний багатосторінковий вебсайт-портфоліо Frontend Developer, створений з використанням HTML5, CSS3 та сучасних технологій адаптивної верстки.

## Опис

Проєкт демонструє навички створення багатосторінкових вебсайтів із використанням семантичної розмітки HTML5, стилізації за допомогою CSS3 та реалізації адаптивного дизайну для різних типів пристроїв.

Сайт містить інформацію про автора, його навички, проєкти та контактні дані. Інтерфейс адаптується до мобільних телефонів, планшетів і десктопних пристроїв.

## Особливості

- Сторінки: `index.html`, `about.html`, `projects.html`, `contacts.html`
- Семантична HTML5-розмітка
- Адаптивний дизайн (Mobile First підхід)
- Flexbox для навігації та розташування елементів
- CSS Grid для побудови макетів і сітки проєктів
- Гамбургер-меню для мобільних пристроїв
- CSS Custom Properties (змінні) для керування стилями
- CSS-анімації та плавні переходи (transitions)
- Адаптивна типографіка з `clamp()`
- Адаптивні зображення
- Форми, таблиці та мультимедіа

## Технології

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Variables
- CSS Animations
