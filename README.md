# Портфоліо

Персональний багатосторінковий вебсайт-портфоліо Frontend Developer, створений з використанням HTML5 та CSS3.

## Опис

Проєкт демонструє навички створення структури вебсайту, роботи із семантичною розміткою HTML5, таблицями, формами, мультимедійними елементами та стилізацією інтерфейсу за допомогою CSS.

Сайт містить інформацію про автора, його навички, проєкти та контактні дані.

## Особливості

- Сторінки: `index.html`, `about.html`, `projects.html`, `contacts.html`
- Статичні ресурси: папки `images/`, `audio/`, `video/`
- Проста структура — легко розгорнути або інтегрувати в більш складний стек
- Flexbox і CSS Grid для створення сучасного макета сторінок;
- CSS-змінні для централізованого керування кольорами та відступами;

## Запуск локально

Просто відкрийте `index.html` у браузері або скористайтеся простим HTTP‑сервером.
